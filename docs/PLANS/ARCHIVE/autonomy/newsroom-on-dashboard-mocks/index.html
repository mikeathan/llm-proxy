Newsroom on the dashboard: Brief and Feed as sub-tabs, like Network

Reading moves to Dashboard › Newsroom, with two sub-tabs, Brief and Feed (the tab called "Alerts" today). The brief keeps its current layout and has no card frame. The Newsroom page keeps only Following and Settings, like the Network page keeps Modules and Settings. All text is sample data. Add ?theme=light for the paper theme.
