# Newsroom on the dashboard: static mocks

Open `index.html` in a browser (add `?theme=light` for the paper theme). It uses the app's tokens and fonts, with no remote files and no build
step. `option-1.png` to `option-7.png` are dark-theme renders of each option in page order (1A, 1A after the link, 1B, 2A, 2A confirm, 2B, 2B
settings). All text is sample data. Plan: [`../newsroom-on-dashboard.md`](../newsroom-on-dashboard.md).
