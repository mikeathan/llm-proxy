# Compact page heads: static mocks

Open `index.html` in a browser (add `?theme=light` for the paper theme). It uses the app's tokens and fonts (`frontend/src/assets/fonts/`), no
remote files and no build step. The dashed line in each phone is measured by the page: where the first card or headline starts on a
390 × 844 screen. The PNGs are renders of it: `case-1.png` to `case-5.png` (dark theme).
All text is sample data. Plan: [`../compact-page-head.md`](../compact-page-head.md).
