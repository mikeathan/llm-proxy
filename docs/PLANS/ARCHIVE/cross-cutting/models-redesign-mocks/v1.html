Models: one place, a short editor, and the running model in view

Today models live in two places: the sidebar's Models page (a list with status) and Settings › Models (five provider tabs, Add and a 20-field edit form with help under every field). Three options below; each answers the same three questions: where models live, how editing works, where the running model shows. The model names are the ones on vertex; everything else is sample data. Add ?theme=light for the paper theme.

With no local model loaded it says "No local model running". It reads what the server already reports (/state → active); nothing new on the server.
