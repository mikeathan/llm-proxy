# Models redesign: static mocks

Open `index.html` in a browser (add `?theme=light` for the paper theme). It uses the app's tokens and fonts, with no remote files and no
build step. `v2-1.png` to `v2-7.png` are dark renders of the v2 frames (cards, list with the side panel, Providers, Engine, Routing, the
dashboard tab, phone); `system-stats.png` is the panel change; `now-*.png` are today's screens (file paths masked); `v1.html` holds the
first three options. Model names are the ones on vertex; the rest is sample data. Plan: [`../models-redesign.md`](../models-redesign.md).
