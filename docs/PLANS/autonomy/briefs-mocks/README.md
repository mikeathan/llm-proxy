# Briefs: static mocks

Open `edition.html` and `settings.html` in a browser (add `?theme=light` for the paper theme). They use the app's real tokens and fonts
(`frontend/src/styles/tokens.css`, `frontend/src/assets/fonts/`), no remote files and no build step. The PNGs are renders of them:
`edition-*.png`, `settings-*.png` (dark, light, phone at 390 px). All text in the mocks is sample data. The mocks show Advanced fields open;
in Simple mode the Advanced block is hidden.
