## Traps found

- A stack is its **own Go module** (`GOWORK=off` is how CI tests it); it may import only `llm-proxy-stacks/sdk`. It cannot import `automation.canonicalURL`, so `sources.CanonicalLink` repeats the rule and a test pins the same cases. Keep them in step.
- ADR-0068 gave the notify port to the Reminders stack **only**, for the owner's own text; ADR-0036 says the core words anything a stack finds. That is why the stack never sends.
- The SDK `Fetch` port is a **guarded GET only**: no header, no POST, 1 MiB cap. Search providers needing headers or POST cannot use it (see `next-stack-moves-and-local-models.md` section 4).
- A model that cites the wrong recent title for a different event hides that item from the notice (shown on the row, not sent). The framework only checks that a citation is in range; it cannot check meaning.
- The `$` helper in this harness hides `grep -c` output when it finds zero matches; count test failures with `awk` instead.
- Telegram `t.me/s/<channel>` pages: no message markup means "no public preview", not "no news" (`ErrShape`). Telegram's terms were read and are unclear for a personal reader; the owner accepted the risk.
- Fixtures were recorded from the dev Mac; vertex's address and egress grant decide whether the hosts answer there.
