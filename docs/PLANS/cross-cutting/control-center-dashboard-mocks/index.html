One control center for every stack

  • A · Stacked overview
    Host health plus one card per enabled stack. Collapse and order remembered. No new library. Phone-friendly.
  • B · Control-center grid
    Arrangeable tiles: size, collapse, maximise, “Add panel” catalogue. Needs a grid library or hand-written drag.
  • C · Device-first
    The device is the centre: Network and Radio facts joined by the core in one view. Stacks become a slim strip.
  • D · Card layouts (B + C)
    Layout presets, cards you resize S/M/L/Full and 1×/2× tall, drag to reorder, content that adapts to the card size. Stacks are control and settings only.
  • E · Boards of cards (recommended direction)
    Dashboard page, boards as tabs, cards as tiles. Home is a mixed board; each stack ships a ready-made board from the same cards. Pin any card to Home. Saved in the browser.

Each mock has a Desktop / Phone switch at the top.
