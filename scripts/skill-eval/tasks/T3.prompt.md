On a real host a radio listen through the privileged helper failed: `iw dev <name> set type` failed with ENOENT while `iw list` worked. iw resolves an interface name with `if_nametoindex`, which opens a Unix socket, and the helper's jail refuses Unix sockets to every child process.

Let the radio class's fixed `ip` and `iw` steps open a Unix socket. The listen program that runs between those steps must keep the refusal. Also put the failing step's program and arguments in the error the helper reports for a failed step, so the journal says which step failed.

The code is under `backend/internal/platform/privhelper/helper/`.
