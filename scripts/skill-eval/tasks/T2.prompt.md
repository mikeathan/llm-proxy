A helper (a sub-agent the main agent hands a task to) has a step limit but no time limit, so a helper that keeps fetching pages can hold the parent run for as long as it likes.

Give each helper run a 5 minute limit. When the limit is reached the run's result has status `assistant.SubRunFailed` and an error text containing `ran longer than`. The limit must be a field named `timeout` (type `time.Duration`, default 5 minutes) on the `Runner` struct in `backend/internal/core/delegation/runner.go`, so a test can set it shorter.

When the parent cancels the run, the result must still be reported as stopped, not failed.
